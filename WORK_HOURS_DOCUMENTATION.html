3. ⏰ Time Formatting (formatTimeToArabic)

Function Purpose

Converts time from API format (list or string) to Arabic 12-hour format with proper Arabic numerals and period indicators (صباحاً/مساءاً).

String formatTimeToArabic(dynamic timeData) { try { // Extract time string from list or use directly if string final timeString = timeData is List && timeData.isNotEmpty ? timeData.first.toString() : timeData is String ? timeData : null; if (timeString == null) return '--:--'; // Parse the time string (format: HH:mm:ss) final parts = timeString.split(':'); final hour = int.parse(parts[0]); final minute = int.parse(parts[1]); // Convert to 12-hour format and determine period final String period; final int displayHour; if (hour == 0) { displayHour = 12; period = 'صباحاً'; } else if (hour < 12) { displayHour = hour; period = 'صباحاً'; } else if (hour == 12) { displayHour = 12; period = 'مساءاً'; } else { displayHour = hour - 12; period = 'مساءاً'; } final arabicHour = _convertToArabicNumerals(displayHour.toString()); if (minute == 0) { return '$arabicHour $period'; } else { final arabicMinute = _convertToArabicNumerals(minute.toString().padLeft(2, '0')); return '$arabicHour:$arabicMinute $period'; } } on FormatException { return '--:--'; } }

4. 📏 Hours Formatting (formatHoursToArabic)

Function Purpose

Converts decimal hours (e.g., 7.9 hours) to a human-readable Arabic format with hours and minutes, including proper Arabic grammar for singular, dual, and plural forms.

String formatHoursToArabic(dynamic hoursData) { try { // Extract hours value from list or use directly if number final hoursValue = hoursData is List && hoursData.isNotEmpty ? hoursData.first : hoursData is num ? hoursData : null; if (hoursValue == null) return '--'; // Convert to double final totalHours = (hoursValue is num) ? hoursValue.toDouble() : double.parse(hoursValue.toString()); // Handle negative values final isNegative = totalHours < 0; final absoluteHours = totalHours.abs(); // Calculate hours and minutes final hours = absoluteHours.floor(); final minutes = ((absoluteHours - hours) * 60).round(); // Build the result string with proper Arabic grammar final parts = <String>[]; if (hours > 0) { final arabicHours = _convertToArabicNumerals(hours.toString()); final hourWord = hours == 1 ? 'ساعة' // singular : hours == 2 ? 'ساعتان' // dual : 'ساعات'; // plural parts.add('$arabicHours $hourWord'); } if (minutes > 0) { final arabicMinutes = _convertToArabicNumerals(minutes.toString()); final minuteWord = minutes == 1 ? 'دقيقة' // singular : minutes == 2 ? 'دقيقتان' // dual : 'دقائق'; // plural parts.add('$arabicMinutes $minuteWord'); } if (parts.isEmpty) return '--:--'; final result = parts.join(' '); return isNegative ? '- $result' : result; } on FormatException { return '--'; } }
⚙️ Conversion Logic: The decimal part is multiplied by 60 to convert to minutes. For example: 7.9 hours = 7 hours + (0.9 × 60) = 7 hours 54 minutes.

bool _shouldShowLateInBadge(dynamic lateInTime) { // Handle null case if (lateInTime == null) return false; // Handle boolean false case if (lateInTime == false) return false; // Handle numeric zero case if (lateInTime is num && lateInTime == 0.0) return false; // Handle list case (e.g., [0.0]) if (lateInTime is List) { if (lateInTime.isEmpty) return false; // Check if all elements are zero return lateInTime.any((element) => element != 0.0 && element != 0); } // If we get here, it's a non-zero value, so show the badge return true; }

6. ➕➖ Difference Calculation Logic

Understanding the Difference Field

The totalLateTime field represents the difference between actual work time and required work time:

  • Positive value: Employee worked LESS than required → Deficit/Late → Display with - prefix
  • Negative value: Employee worked MORE than required → Overtime → Display with + prefix
  • Zero: Exact match → No prefix needed

Processing Flow:

Step 1: Extract numeric value from API data (list or direct number)
Step 2: Format the time using formatHoursToArabic()
Step 3: Determine sign based on numeric value
Step 4: Apply appropriate prefix and color
Step 5: Display result to user
// Extract numeric value to determine sign final numericValue = _extractNumericValue(totalLateTime); final formattedTime = formatHoursToArabic(totalLateTime); // Determine display based on numeric value final String displayTime; if (numericValue == null || numericValue == 0) { displayTime = formattedTime; // No prefix } else if (numericValue < 0) { // Negative value = overtime, remove - and add + displayTime = '+ ${formattedTime.replaceFirst('- ', '')}'; } else { // Positive value = deficit/late, add - prefix displayTime = '- $formattedTime'; } // Apply color based on value final color = numericValue != null && numericValue < 0 ? context.colors.success // Green for overtime : context.colors.error; // Red for deficit

Field Descriptions

Field Type Description Example

⚠️ Important: Fields like late_in_time, early_out_time can have multiple formats:
  • null - No data
  • false - Boolean indicator
  • 0.0 - Direct numeric zero
  • [0.0] - List with zero
  • [1.5] - List with actual value
All helper functions handle these variations automatically.
